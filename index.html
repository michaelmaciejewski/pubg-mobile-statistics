Save & Backup

Where your data lives and how to keep it safe.

Your data is stored in this browser on this device. Clearing site data, a private window, or switching browser or device starts empty. A spreadsheet sync, a backup file or a linked save file protects you from all of those, and a Google Sheet also works across devices.

Connect a Google Sheet

A one-time setup, about 3 minutes. The script lives in your own Google account.

  1. Open your Google Sheet, then choose Extensions → Apps Script.
  2. Delete any code there, paste the script below, and save.
  3. Choose Deploy → New deployment, pick the type Web app, set Execute as: Me and Who has access: Anyone, then deploy and approve the permissions.
  4. Copy the Web app URL (it ends in /exec), paste it below and press Connect.
Token (a private password, already put into the script)

Web app URL

The sheet is open to anyone who has both the URL and the token, so keep them private. On every save the dashboard updates only the rows that changed and adds new seasons in the next empty row. Formula columns such as K/D Ratio, Win Ratio, Top 10 Rate and AVG Damage are never overwritten, Records can only be removed in the sheet: delete the row there and the dashboard follows on its next sync. If you change the token, copy the script again and redeploy.
